最近看到有人分享 Hugging Face 推出的终端聊天功能。官方宣传语很简单：

> no config. no key. nothing  
> chat with open models, zero setup

也就是不用配置、不用 API Key，直接在终端里和开源模型聊天。

## 怎么使用？

在 Windows 的 CMD、PowerShell，或者 macOS、Linux 的终端里运行：

```bash
ssh https://chat.hf.co
```

注意，这不是让你把网址直接放进浏览器打开，而是通过 SSH 命令连接。进入界面后，就可以选择模型聊天。我测试时能选到 `Qwen/Qwen3.8-27B`，也能看到其他开源模型。

Hugging Face 还提供了 SSH 公钥绑定方式。如果想争取更好的使用额度，可以登录账号后添加公钥：

- 聊天入口：<https://chat.hf.co>
- SSH 公钥设置：<https://huggingface.co/settings/keys>

## 免费，但不是绝对无限制

这个功能确实能用，不需要一开始就准备 API Key，也不用自己部署模型。不过，“免费使用”不等于永远不限量。输出可能被截断，使用频繁时也可能遇到速率限制。它目前更像是一个实验性、轻量级的入口，稳定性和体验以后也可能变化。

## 我的实际体验

我自己试了一下，感觉比较一般。

功能有限，响应速度也偏慢。虽然可以在终端里直接和开源模型聊天，省去了配置 API 的步骤，但实际用起来，并没有让我觉得比手机上直接打开豆包、DeepSeek 这类应用方便多少。

如果只是偶尔尝鲜，可以体验一下；但如果是为了日常聊天、写东西或者解决问题，我暂时看不出它有什么特别值得专门折腾的地方。

## 总结

Hugging Face 这个终端聊天功能是真的，不是什么骗局，也确实降低了体验开源模型的门槛。

但对我来说，**能用不代表好用，免费也不代表值得花时间。** 试过就行，目前没必要把它当成日常主力工具。
